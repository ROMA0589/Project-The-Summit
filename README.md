# The Summit at Breckenridge

¡Bienvenido a tu proyecto web sobre The Summit en Breckenridge!

Este sitio presenta información sobre el centro de esquí, actividades y cómo llegar, con un diseño moderno y adaptable.

## Estructura del proyecto
- `index.html`: Página principal del sitio.
- `style.css`: Estilos personalizados.
- `starting.css`: Estilos base o de arranque.
- `LICENSE`: Licencia MIT.

## ¿Cómo ver el sitio?
Abre el archivo `index.html` en tu navegador web favorito.

## Publicar en GitHub Pages
1. Ve a la configuración (Settings) de tu repositorio en GitHub.
2. Busca la sección "Pages".
3. Selecciona la rama `main` y la carpeta raíz (`/`).
4. Guarda los cambios.
5. Accede a la URL que te proporciona GitHub Pages para ver tu sitio publicado.
